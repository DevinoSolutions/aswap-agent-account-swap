# Security

aswap stores OAuth credentials for your Claude Code and Codex accounts on your machine, so security reports are taken seriously.

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/DevinoSolutions/aswap-agent-account-swap/security/advisories/new), or by email to hello@devino.ca. Do not open a public issue. We aim to acknowledge reports within three business days.

When filing, never include real tokens, session keys or the contents of `~/.claude/.credentials.json`.
